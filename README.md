# Gas & Flame Detection System

An electronics and embedded-systems project designed to demonstrate gas and flame detection using suitable sensors and a microcontroller.

## Overview

This project explores how sensor inputs can be used to identify potential gas leakage or flame conditions and activate an alert system.
